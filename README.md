# Matcha Matcha demo for Android

Demonstration builds of the app: one app for each role, and the earlier all-in-one demo. Every customer, order and payment in them is simulated.

The four role apps install side by side and each keeps its own data; they do not talk to each other. Press and hold the logo at the top of an app for its demo controls.

- `index.html`: the download page, served by GitHub Pages.
- `matcha-matcha-*.apk`: the Android packages.

These are private demonstration builds, not the published app.
