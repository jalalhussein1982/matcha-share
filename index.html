Matcha Matcha app demo for Android

A clickable prototype of the app, packaged so it can be tried on a phone or tablet. Every customer, order and payment in it is simulated.

Download the APK

Version 0.2.1 · 4.8 MB · Android 7.0 or later

This file installs on Android only. Open this page on the Android device, or download the file here and move it across.

How to install

  1. Tap Download the APK, then open the file from the download notification or the Files app.
  2. If Android says the browser is not allowed to install apps, tap Settings, switch on Allow from this source and go back.
  3. Tap Install. If Play Protect says it does not recognise the app, choose Install anyway: the demo is not on Google Play.
  4. Open Matcha Matcha from the app list.

Good to know

  • Nothing is real. No account is created, no payment is taken and nothing leaves the device.
  • Each device keeps its own data. A phone and a tablet do not share customers or orders.
  • Replacing an older copy. If an earlier build of the demo is installed and Android refuses the update, uninstall the old one first.
